Import a Live Video
Paste a YouTube live link to fetch the title, description and thumbnail automatically. For any other provider, paste the stream link and fill in the details below.
How it works

YouTube lives behave exactly like the YouTube video import: paste the link, press Look up and the details come back. Any other provider expects a direct stream link (for example an .m3u8 or .mp4 URL); you then complete the title, description and category yourself before importing.
