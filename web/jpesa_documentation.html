API Documentation
To offer a more comprehensive platform, we publish an API Mode model which provides a real-time interface with our systems. The API is a white-label solution that enables you to integrate the API application with your system so you can brand and sale our services directly from your system.

Credit GWallet
Use this command to credit (add money) to your JPesa GWallet. One other way to put it is to pull funds from your clients or associates to your GWallet

PHP Post Example



Parameters Description Example
_key_ Your API Key XYZ123QWE
mobile The MSISDN Number 256752567374
amount The amount of money to be pulled from the MSISDN and credited to your account 1000
act_to [optional] The account number to credit 323432
callback [optional] This URL will be automatically called once the payment is complete. When called, the return variables will be attached to it in the format http://url.com/order.php?tid=BCEA96C43987D3&status=approved&memo=101&ref=1234 http:/url.com/order.php
tx [optional] This is your own defined transaction id. It will be passed back to your callback or return URL. When defined, we will also use it to check against API based duplicate transactions 12345
Return Variables
Typical Example
{"tid":"BCEA96C43987D303705DF48C1A058067","memo":"351","msg":"[[S000103]] MM transaction initiated","_api_log_":"1596587","api_status":"success"}
APIStatus

Status of the transaction query.

  • SUCCESS - Transaction is successful
  • ERROR - Transaction failed and or something went wrong
tid Transaction ID. A unique number that corresponds to the transaction request. Use this to monitor the status of Memo
memo Memo or credit note number. A unique number that corresponds to the credit request.
message A textual response. Will also have the reason if transaction fails.

Transaction Information
Use this command to get information about a particular transaction

PHP Post Example



Parameters Description Example
_key_ Your API Key XYZ123QWE
tid The Transaction ID 37721E0AF986000000C15F03AD7A767
pid (Optional) The PP Transaction ID 1234567890
cur Passing this parameter instead of the default tid above will return the account info (balances) in the respective currency.

JPesa Commerce Platform for Business

JPesa Commerce Platform is a full-stack payment processing solution that helps you accept and make payments globally.

To offer a more comprehensive platform, we publish an API Mode model which provides a real-time interface with our systems.

The API is a white-label solution that enables you to integrate the API application with your system so you can brand and sale our services directly from your system.

Accept payments

Accept payments from customers all over the world. Give your customers flexibility to pay the way they want, including:
  • JPesa exclusives, like JPesa Credit.
  • Debit or credit cards, like Visa, Mastercard, and American Express.
  • Alternative payment methods, like EFT, RTGS, and more.
Make payments

Make payments to multiple recipients at once. Send payouts in different currencies than your JPesa balance.
